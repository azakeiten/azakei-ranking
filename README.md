# 本日の億万長者 — AZAKEI 麻布経済展 チップランキング

https://azakeiten.github.io/azakei-ranking/

麻布経済展（AZAKEI）で使う、チップ獲得ランキングです。教室の黒板に書いたような見た目で、管理者が入力すると数秒でお客さん側の画面も書きかわります。

- お客さん用：https://azakeiten.github.io/azakei-ranking/
- 管理者用：https://azakeiten.github.io/azakei-ranking/#admin （合言葉が必要）
- 見た目の確認用（見本データ）：https://azakeiten.github.io/azakei-ranking/?demo

## しくみ

- ページは GitHub Pages で公開しています。
- 記録は Google スプレッドシートに保存します。ページは数秒おきにそこを読みに行きます。
- 書き込みには合言葉が必要です。合言葉は Google 側（スクリプト プロパティ）にだけ置き、このリポジトリには書きません。

## 記録の保存先をつくる（最初に1回だけ）

1. Google ドライブで新しいスプレッドシートを作る（名前は「AZAKEI ランキング記録」など）。
2. メニューの「拡張機能 → Apps Script」を開く。
3. 最初からある `コード.gs` の中身を全部消して、このリポジトリの [`apps-script/Code.gs`](apps-script/Code.gs) を貼り付けて保存する。
4. 左の歯車「プロジェクトの設定」→ いちばん下の「スクリプト プロパティを追加」で、
   - プロパティ：`ADMIN_PASS`
   - 値：管理者の合言葉（スタッフだけに伝える）

   を登録して保存する。
5. 右上の「デプロイ → 新しいデプロイ」→ 種類の歯車で「ウェブアプリ」を選び、
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**

   にして「デプロイ」。初回は Google の許可画面が出るので、自分のアカウントで許可する。
6. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピーする。
7. このリポジトリの [`config.js`](config.js) の `scriptUrl: ""` の `""` の中にその URL を貼って保存（コミット）する。

数十秒後にページを開き直すと、黒板が保存先につながります。

### コードを直したとき

Apps Script のコードを変えたら「デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ」で更新します。URL は変わりません。

## 当日の使い方

- 教室のモニター：お客さん用ページを開いて「全画面で映す」。1位が入れかわると、黒板消しが前の1位を消し、チョークで新しい1位と「新記録！」が書き込まれます。
- 入力係：スマホで `#admin` のページを開き、合言葉を一度入れる（その端末に記憶されます）。名前・枚数・日付を入れて「黒板に書く」。
- 書きまちがい：管理者ページで、黒板の記録の「消す」→「本当に消す」。スプレッドシートを直接直してもかまいません。
- 記録はスプレッドシートにそのまま残るので、あとで集計や振り返りにも使えます。
